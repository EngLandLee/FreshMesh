# Public introduction — Persuade / Read

Audience: a mini-mart operator, student contributor or reviewer arriving from GitHub.
Within the first viewport they should understand stock transfer with accountability,
see the real operational interface and choose source startup or the documented demo.

Inherit DESIGN.md's forest/paper palette, typography fallbacks, restrained borders
and existing product truth. Do not replace the portal, change its PKCE callback or
claim a public business backend. The page is public at GitHub Pages; the same tracked
HTML/CSS is served locally at /about/. Keep portal root and API/auth URLs unchanged.

Composition: two-column mechanism-and-evidence introduction; editorial problem
statement; numbered five-step handover; distinct headless foundations; actual-image
gallery; readable source commands; source/license close. Responsive single-column
reading at 390px. No customers, testimonials, efficiency claims, sponsors or score
claims. Screenshot data is synthetic and explicitly labelled. Native anchor
navigation, visible keyboard focus and reduced-motion support; no unnecessary JS.

Banner is original typographic SVG with precise transfer-node geometry; no third-party
logos or source-repository promotion. Screenshot provenance and Apache notices are
generated by scripts/ui-smoke.mjs and scripts/site-smoke.mjs. Raster screenshots stay
in dist/workflow/release assets, not the source archive. The static website package
rewrites versioned public image URLs to local verified image files for Pages.
